# API 检查输入

这些文件是兼容性检查的数据，不是第二套接口手册。日常查询使用 `go doc -all ./<包>`。

| 文件 | 作用 | 更新规则 |
| :--- | :--- | :--- |
| [inventory.md](./inventory.md) | 当前源码的导出声明快照 | 由 `make api-inventory` 生成，不手改声明 |
| [baselines/v1.0.0.md](./baselines/v1.0.0.md) | 首个稳定版本的导出声明基线 | 发布前按最终候选生成；发布后冻结，不随当前源码更新 |

```bash
make api-inventory-check
make api-compat-check
```

两项检查分别核对当前快照、检测相对 v1.0.0 的删除与签名变化。
不保留预发行基线或破坏性变更例外文件。兼容新增允许通过，删除、改名和签名变化会失败；
不能通过重新生成稳定基线来绕过检查。后续 minor 版本的新 API 同样受 SemVer 保护，
发布新 minor 时应切换到覆盖已有声明的最新稳定基线，不能回退到首版快照。

声明比较不等于语义兼容：TTL、序列化、消息投递和资源所有权变化仍需回归测试与
[升级策略](../migration.md)。第三方类型出现在公共 API 时，上游不兼容升级也需要审阅。

v1 系列遵守 SemVer，不以是否有已知下游调用为判断标准。
发布操作见[发布流程](../release.md)。
