- [缓存查询](../examples/cached-query/README.md)：数据库、缓存和重建锁的组合。

## 配置与安全

- 配置变更通知不会重新装配组件；应用决定替换、请求切换与旧资源释放的顺序。
- 不输出完整配置、DSN、JWT 或密码；生产连接配置可信 CA、主机名校验和 ACL。
- Metrics 管理端口和示例调试接口应限制网络访问，不能直接暴露公网。
- 多租户入口先认证，再从可信上下文构造幂等 identity scope；客户端 Header 不是证明。
- 校验租约丢失、限流后端不可用、结果过大和去重存储满等失败路径，不只验证正常请求。

## 超时与退出

启动、请求 I/O 和后台工作使用各自的有限预算。脱离请求取消的共享任务也需要独立
超时和退出管理，不能因此把工作变成无限后台任务。

收到退出信号后：

1. 停止接收新请求，并给已接收请求有限的完成时间。
2. 排空 MQ 消费；超时后选择关闭或交给持久消费进度恢复。
3. 停止 Watch、WorkerID 保活、锁续期和其他后台任务，再关闭借用的 Connector。
4. 关闭应用创建的 gRPC 连接，随后关闭可观测性和根 logger 等基础资源。

清理使用新的有限 context，不复用已取消的请求预算。Go 不能强制终止忽略 context
的 Handler；Drain 超时不意味着副作用已经停止。

## 部署前验证

在应用环境验证凭证、TLS、后端拓扑、持久化、重启恢复、容量及备份。
Testcontainers 是组件回归，不是应用验收；分布式锁与去重缓存也不能替代业务存储的
唯一约束或版本/CAS。版本升级见[迁移说明](./migration.md)，扫描策略见[安全政策](./security.md)。
