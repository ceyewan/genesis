# 升级与兼容策略

v1.0.0 是 Genesis 的首个稳定版本。接入时直接参考组件 README、GoDoc 和
[examples](../examples/README.md)，本页不保留预发行版本的迁移历史。

## 稳定版本

- Patch 版本用于兼容性修复；minor 版本可以增加兼容能力。
- 删除公开 API、改变不兼容的签名或行为，应在新的 major 版本发布。
- 导出声明由 [API 兼容检查](./api/README.md)约束；检查通过不代表所有行为都兼容。
- 状态编码、配置解析、消息投递、TTL、租约或资源所有权发生变化时，发布说明必须写明影响和升级动作。
- 不默认承诺不同版本的有状态组件可以混部；升级前审阅具体组件的说明。

## 应用升级

1. 阅读目标版本的 [Release Notes](https://github.com/ceyewan/genesis/releases)。
2. 更新依赖、编译并运行自己的集成测试，不只检查构建是否成功。
3. 验证错误映射、超时、资源关闭，以及 MQ、缓存、幂等和锁的业务语义。
4. 涉及持久化状态时，按发布说明安排切换、回滚和数据处理。

首次接入的运行与安全要求见[生产接入](./production.md)，逐组件限制查各包 GoDoc。
